# Player's Reputation

**Player's Reputation** — это веб-приложение, предназначенное для сообщества игроков в покер. Оно служит хабом для отслеживания репутации игроков, предоставляя бэкерам (спонсорам) и администраторам инструменты для проверки, добавления и управления данными об игроках.

## ✨ Ключевые возможности

* **Аутентификация и авторизация:** Безопасная регистрация и вход для пользователей.
* **Ролевая модель:** Разграничение доступа для разных типов пользователей (бэкер, администратор).
* **Поиск игроков:** Мощная система поиска с базовыми и расширенными фильтрами.
* **Управление записями:** Возможность для верифицированных бэкеров добавлять и редактировать записи об игроках.
* **Процесс верификации бэкеров:** Бэкеры проходят процедуру проверки для получения полного доступа к платформе.
* **Административная панель:** Инструменты для администраторов для управления заявками на верификацию и другими системными задачами.
* **Информационный портал:** Главная страница с общей информацией о проекте и формой обратной связи.

## 🛠️ Технологический стек

* **Фреймворк:** React 18
* **Сборщик:** Vite
* **Язык:** JavaScript (ESNext)
* **Стилизация:** Sass (SCSS) с использованием CSS Modules
* **Управление состоянием:** MobX
* **Роутинг:** React Router DOM v7
* **Работа с API:** Axios
* **Управление формами:** React Hook Form
* **Валидация схем:** Yup
* **Анимации:** GSAP, React-spring

## 🚀 Начало работы

### Требования

* Node.js (версия >=18.0.0)
* NPM или Yarn

### Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <your-repository-url>
    cd frontend
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Настройка окружения:**
    Создайте файл `.env` в корневой директории `frontend` и добавьте переменную для URL вашего бэкенд-сервиса:
    ```
    VITE_API_URL=http://localhost:8080
    ```
    Это значение используется в конфигурации Axios (`src/shared/api/api.js`).


4.  **Запуск в режиме разработки:**
    Этот скрипт запустит dev-сервер Vite.
    ```bash
    npm run dev
    ```

### Сборка проекта

* **Для разработки (с sourcemaps):**
    ```bash
    npm run build:dev
    ```

* **Для продакшена (минифицированная версия):**
    ```bash
    npm run build:prod
    ```
